# WikiSouls ⚔️

Este é um projeto de site experimental desenvolvido com o objetivo de praticar e consolidar conhecimentos em **HTML** e **CSS**, com foco principal em:

- Layouts utilizando **Flexbox**
- Organização de páginas
- Estilização e responsividade básica
- Estruturação semântica

## 📚 Sobre o projeto

O site foi inspirado na franquia *Dark Souls*, trazendo uma espécie de wiki com informações sobre os jogos da série.

⚠️ **Importante:**  
Este não é um projeto finalizado ou profissional — trata-se de um ambiente de testes e aprendizado.

## 🚀 Tecnologias utilizadas

- HTML5
- CSS3
- Flexbox


## 🎯 Objetivo

O objetivo deste projeto foi praticar:

- Construção de layouts modernos
- Uso de **Flexbox** para alinhamento e organização
- Separação entre estrutura (HTML) e estilo (CSS)
- Criação de múltiplas páginas interligadas
